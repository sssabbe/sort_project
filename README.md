# Эволюция алгоритмов сортировки

Учебный проект по АиСД: сравнение пузырьковой сортировки, сортировки выбором, сортировки вставками, быстрой сортировки и сортировки слиянием.

## Требования
- Python 3.10 или новее.
- Для построения графиков используется библиотека `matplotlib`.

## Установка зависимостей
Перед запуском графиков установите библиотеку:
```bash
pip install -r requirements.txt
